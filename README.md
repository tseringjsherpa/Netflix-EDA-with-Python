# 📺 Netflix Data Analysis

A simple exploratory data analysis and machine learning project on the Netflix content dataset.

## 📊 Project Overview
This project explores Netflix movies and TV shows to uncover patterns in content type, ratings, and release trends.  
It also applies a **Multiple Linear Regression** model to predict movie duration.

## 🔍 Analysis Performed
- **Exploratory Data Analysis (EDA)**
  - Distribution of content types, ratings, and release years  
  - Relationship between features  
  - Trends in content release over time
- **Machine Learning**
  - Multiple Linear Regression for duration prediction

## 🛠️ Technologies Used
- Python 3.x  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn
